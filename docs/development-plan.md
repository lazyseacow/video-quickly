## 已完成的制作能力

此前按以下顺序完成了主要制作功能；Windows 原生联合 UI 路径和真实云服务仍需对应环境验收。

1. **资料核验与镜头引用（已实现，专项验收通过）**：真实正文采集、文本／PDF 导入与关键词检索；固定原文和校验值；模型只提出有原文摘录的待核验候选；人工审阅、修改和绑定镜头；引用编号可选显示并随导出保存完整目录。资料／引用加入统一撤销、草稿和备份，保护外部修订、锁定镜头及原有人工资料。
2. **字幕与系列模板（已实现，本地验收通过）**：可编辑并保存字幕字体、字号、配色、位置等样式，预览与真实编码一致；保存和复用系列风格／场景／字幕预设，应用前预览范围，保留明确的项目快照、撤销和恢复语义。
3. **多选批改（已实现，本地验收通过）**：时间轴与镜头列表多选、连续范围选择和全选；批量改时长／样式及复制样式，锁定与真实素材边界检查；一次确认产生一步可撤销命令，不覆盖未选择镜头。
4. **声音精修（已实现，本地验收通过）**：项目响度与旁白压低音乐、镜头增益／降噪均可关闭；主预览及导出共用实际 48 kHz 双声道混音，100 Hz 电平窗口显示真实峰值与 RMS。文稿词句、手选区间及实际停顿候选可先试听再同步删除音视频／字幕，并恢复当前分割／裁剪源窗口。逐词仅使用来源匹配的真实识别时间戳，手改和估时不冒充逐词对齐。

声音精修已接入共享、不可原地改写的 Source／Plan 和微秒时间映射，原始字幕只存一份；分割、裁剪、批改及文稿删除使用计划窗口。项目总帧采样、分数帧率字幕边界和跨短删除区间的连续播放均通过真实媒体回归，包括 30 fps 删除一帧后的连续播放、24→30 fps 采样一致及无视频帧回调时的回退路径。
