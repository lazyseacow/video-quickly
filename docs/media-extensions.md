# 素材扩展与剪辑交付

场景、道具参考、切图和改图仍在现有创作设置、素材库与镜头候选中使用。内置制作流程保留四个阶段。

## 场景与道具参考

在制作设置的创作设定中展开场景或道具的参考图，可选择或导入最多四张公共图片。每个镜头只使用其引用的设定图片；实际请求按角色、场景与道具的顺序去重。协议限额按合计图片数计算，运行前检查文件大小、哈希、归属和服务能力。

作品默认设置可携带这些引用。已有分集仍通过显式同步更新；运行和实验使用固定快照。生成后修改引用会阻止旧候选应用。已被项目、作品或实验使用的图片受占用保护。

## 网格切图与局部改图

素材库图片卡片提供“网格切图”，支持 1–8 行、1–8 列。整数像素边界完整覆盖原图，不能整除时不丢失边缘像素。结果作为独立 PNG 素材保存，记录源素材、源 SHA-256、像素区域与网格编号。相同源图和网格重复请求复用有效切片，并补齐已移除或缺失的结果。切图后逐张预览，再通过既有操作绑定镜头或设定。

在镜头候选中选择图片模型，使用支持 OpenAI Images 编辑协议的模型时可勾选“局部改图”。设置像素区域并填写调整要求后，系统生成同尺寸透明遮罩，提交源图、参考图和遮罩。源图排第一；透明区域表示希望修改的部分。模型对遮罩边缘的遵循需查看实际结果。支持源 PNG、JPEG、WebP，单张源图上限 20 MiB，遮罩为不超过 4 MiB 的透明 PNG。

改图产生新的镜头候选。原图与当前绑定保留，显式应用后沿用项目撤销机制。继续原运行使用原回执；显式重新制作仍保留源图与遮罩，未知提交不会自动换模型或重发。协议依据：[OpenAI Images 编辑接口](https://developers.openai.com/api/reference/python/resources/images/methods/edit)。本地 HTTP 夹具验证协议，不代表真实模型质量或账单验收。

## 模型建议与对话修改

流程画布与制作设置的任务高级区提供替代模型和对话修改入口。替代建议按当前已配置模型的能力、协议、故障类型和配置价格展示。选择只改变下次配置；已提交运行继续使用原模型和回执。配置价格不是供应商实际账单。

对话修改仅允许任务名称、提示词和模型三个字段，保留变量绑定。生成建议沿用运行快照、费用记录、取消和持久化回执；同一启动请求重试不会再次生成。无效回复保存原文与用量，不能应用。关闭后重开可读取已有建议；应用时核对项目修订和完整节点基线，写入现有编辑草稿，可撤销和重做。项目修订变化后需显式新建建议。

建议提交结果未知时，先在服务端核对原任务状态与用量。仍在执行或重启后排队的本地建议任务需先显式停止；已结束的未知任务可选择“核对后新建”。确认只打开新建议的输入，原运行与回执保留；再次点击“生成修改预览”才会提交独立任务，并可能另行计费。

## 剪映／CapCut 工程导出

保存项目后打开“导出 → 其他导出 → 剪映／CapCut 工程”。本地导出冻结当前修订和素材，不修改源项目或已安装软件的草稿库。

- 不选择模板：生成剪辑交接包，包含按分镜保留剪切点的合成画面、独立 PCM 混音、字幕、相对路径的 `compile.json` 和带哈希的清单。
- 选择本机目标软件创建的明文空草稿模板：额外生成实验性草稿，保留模板的软件标记。加密模板、非空模板、目标不符及损坏素材会被拒绝。

画面动画、裁切与转场已合成；声音为合并后的混音，无法在目标软件按原始音源逐个调整。字幕保留文字与时间，目标软件字体及排版需核对。交接包的相对路径可迁移；实验性草稿中的绝对素材路径搬移后需重新链接。

格式参考采用 [capcut-cli 固定提交](https://github.com/renezander030/capcut-cli/tree/5d4220a8e1845642cebb89d188e63713c1f0ccfc) 的 MIT 字段默认值，未新增运行依赖；完整授权声明见根目录 `THIRD_PARTY_NOTICES.md`，也附在每次导出中。已核对该项目的[版本兼容记录](https://github.com/renezander030/capcut-cli/blob/5d4220a8e1845642cebb89d188e63713c1f0ccfc/docs/version-support.md)，不使用固定旧版本空模板宣称兼容所有编辑器。

**本批只验收本地文件生成。剪映／CapCut 实际导入，以及 macOS 实际应用包尚未验收。** 是否可被某个软件版本打开，以该版本的真实导入检查为准；导出界面和清单均保留此边界。

## 数据兼容与验证入口

工作区迁移 15 在升级前沿用现有备份机制，增加场景／道具图片引用投影并保护新增契约。包含图片设定或裁切来源的备份使用格式 8；格式 4–7 仍按各自能力导入。恢复会重映射引用并校验来源哈希、真实像素尺寸和裁切记录。

验证使用 `pnpm check`、`pnpm test:media`，相关浏览器用例为 `creative-reference-images.spec.ts`、`workflow-assistant.spec.ts`、`media-extensions.spec.ts`。真实 Windows 包由 `pnpm test:desktop --packaged` 验证，包含隔离工作区中的 IPC、RGBA 遮罩、候选、建议快照与实际剪辑交接包导出。模型测试仅连接本地夹具，不产生付费调用。
