# Video Quickly

可逐步微调的视频创作工作台。以历史手绘科普为首个模板，支持项目、分镜、视频规格、模型和 Skill 管理，以及持久化的步骤执行与人工审阅。

## 开发

运行环境为 Node.js 24 LTS、pnpm 10。首次运行：

```powershell
pnpm install
pnpm dev
```

打开 <http://127.0.0.1:1420>。开发预览连接同一套 TypeScript 执行层，数据保存在 `.data/development/`；`VIDEO_QUICKLY_DATA_DIR` 可指定隔离数据目录。此桥接只用于 Vite 开发与浏览器验收，正式桌面客户端使用原生 IPC。

浏览器验收使用 `pnpm test:e2e`：自动构建独立的测试前端产物，以真实本地执行层与事件通知运行全部流程。`pnpm dev:e2e` 可手动启动该预览，默认使用 `.data/browser-preview/`；测试模式不会替换正式桌面构建。

桌面应用使用 Tauri IPC 与 Node 附属进程通信。桌面开发与打包另外需要 Rust MSVC 工具链、Visual Studio C++ Build Tools 和 WebView2。桌面开发前先构建随附组件：

```powershell
pnpm build
node scripts/prepare-sidecar.mjs
pnpm dev:desktop
pnpm build:desktop
```

FFmpeg 和 FFprobe 需要完整媒体构建。开发模式自动发现 `.tools/` 中的便携构建，也可设置 `VIDEO_QUICKLY_FFMPEG` 和 `VIDEO_QUICKLY_FFPROBE`。安装包准备脚本可通过 `VIDEO_QUICKLY_MEDIA_DIR` 指定包含媒体组件与许可声明的目录。

模型服务由用户配置；本地示例素材用于检查编辑和渲染，旁白与事实主张仍待核验。未加入旁白音频时，导出面板会标明静音画面小样。

## 验证

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```

首次运行浏览器验证时可执行 `pnpm exec playwright install chromium`。测试应使用临时数据目录，隔离真实模型与用户项目。媒体测试使用真实 FFmpeg；云端调用测试仅替换网络边界。

Windows CI 会执行构建、真实媒体导出与隔离安装检查，并上传安装包和验证清单。固定媒体组件可通过 `pnpm prepare:media` 准备。数据库升级、重连规则及原生人工验收边界见 [Windows 交付与恢复验收](docs/windows-verification.md)。

## 工程结构

- `apps/desktop`：React 工作台及 Tauri 原生外壳。
- `packages/contracts`：TypeScript 类型、Zod 输入契约、视频规格及工作流定义。
- `packages/runtime`：LangGraph 编排、SQLite 持久化、模型与 Skill 管理、进程通信。
- `packages/integrations`：模型媒体适配、自定义 HTTP 请求、ComfyUI 映射和远端任务回执。
- `packages/video`：场景预览、时间轴、字幕和视频输出。
- `.agents/skills/make-interfaces-feel-better`：本项目采用的前端设计与验收 Skill。
- `.agents/skills/gsap-*`：GreenSock 官方的动画、React、时间线和性能 Skill，保留固定版本、来源和许可。

## 制作流程

简报 → 资料与史实 → 风格与角色 → 旁白与分镜 → 素材 → 配音字幕 → 动画运镜 → 小样审阅 → 导出。

步骤视图与流程图操作同一份工作流，支持依赖连接、条件分支和人工审阅。项目规格与素材生成规格分别管理，帧率按分数保存，镜头时间以微秒保存，运镜按镜头时间计算。修改项目会创建新修订，已有运行固定原快照。

在工作台编辑镜头旁白、画面、时长和运镜；在项目设置调整尺寸、比例和帧率；导出面板可单独覆盖输出规格。模型生成的分镜与风格作为步骤产物保存，审阅后可应用到项目，修订检查会阻止覆盖后续人工修改。

时间尺支持持续拖动，画面随位置更新，编辑中的镜头保持选中。方向键按项目帧率前后移动一帧，按住 Shift 移动十帧，Home / End 定位首尾，Space 播放或暂停。时间轴缩放尽量保持播放头在视口中的位置，适配按钮恢复完整视图。播放到末尾会停止，再次播放从开头开始；切到后台时暂停。

时间轴参考 [Kdenlive 轨道界面](https://docs.kdenlive.org/en/user_interface/timeline.html) 与 [Shotcut 时间轴](https://forum.shotcut.org/t/user-guide-table-of-contents/43285) 的信息层次：固定 V1／A1 轨道头，视频与旁白分轨显示，片段区独立滚动。视频片段显示真实预览缩略图、名称与时长；旁白区区分已关联音频和待配音占位，播放头贯穿刻度与片段区。缩放滑块与加减按钮共用当前位置锚点。

选中镜头后可用时间轴剪刀按钮或 S 在播放头处分割，两侧至少保留 0.5 秒的完整帧。拖动片段调整顺序；拖动所选片段两端调整入出点，默认吸附到镜头边界与播放头，按住 Alt 可临时关闭吸附。裁剪手柄支持方向键逐帧调整，Shift 调整十帧；窄片段可通过属性中的素材入出点编辑。已关联音视频时先读取真实时长，出点按项目帧率限制在素材内；无媒体的二维场景允许延长。分割、裁剪与一次重排各为一步撤销，保存期间的新输入会保留。分割后的素材、运镜和字幕延续原时间位置，预览与导出共用区间。

镜头列表与画面／旁白轨共用多选：Ctrl／⌘ 点击增减，Shift 点击连续选择；列表或时间轴焦点内 Ctrl／⌘ A 全选，Escape 清除，输入框保留原生文本操作。所选组可整体拖动、前后移动、复制和移除；批量编辑可预览时长、运镜、字幕及样式复制的范围。时长修改先读取各镜头实际使用的素材，按项目帧率与原有末帧／静音补齐规则检查；任一目标锁定或相关内容更新会整批拒绝。复制样式保留各镜头正文、引用、媒体与图表数据。一次批改进入一步撤销并跨重载恢复，保存失败可重试同一份草稿；保存中关闭弹窗仍继续保存。删除等待期间有新输入时保留镜头并提示重新核对。

旁白轨显示从真实音频解码的波形，按素材哈希缓存并优先加载可见片段；分割、裁剪后显示对应的源区间，无法解码时明确提示。波形是派生数据，不写入项目或撤销历史。

在镜头的“配音”区域打开“编辑字幕”，可修改每句文字和入出时间、排序、拆句、添加、删除和定位。时间以当前镜头起点为零；裁剪窗口外的原字幕仍保留，扩回素材后可重新显示。旧旁白的自动时间分配明确标为估时，选择支持时间戳的 OpenAI 兼容 ASR 模型后可按音频识别对齐；识别结果先作为候选展示，确认应用才修改项目，并可整步撤销。接口需返回真实的 `segments` 或 `words` 时间戳，纯文字结果会拒绝作为对齐字幕；单次音频上限 25 MB。高级参数 `timestampGranularity` 可设为 `word`，`asrResponseFormat` 可设为 `diarized_json`，具体支持以所接服务为准。协议见 [OpenAI 转录接口](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)。长句在预览与 SRT／烧录时自动分页，页内切换按阅读量估时；原句段与语音时间戳保持不变，需要逐词精确显示时请拆句校准或使用逐词对齐。

“背景音乐”可选择素材库音频或导入文件，设置项目起点、素材入点、时长、音量及淡入淡出。循环范围为素材入点至音频末尾；音乐跟随项目时间，镜头重排不会移动音乐。A2 轨显示音乐与真实波形，预览及 FFmpeg 导出使用相同的播放与音量规则。音乐编辑可撤销并跨重载恢复，备份会包含引用的公共音乐，导入时恢复为独立素材。

项目设置的“项目混音设置”可开关响度处理、调整目标 LUFS 与真峰值，并设置旁白压低背景音乐的阈值、比例、起音与释放时间；镜头配音区的“镜头声音处理”调整增益及可关闭的降噪。试听先准备真实处理后的混音，主预览与导出共用 48 kHz 双声道音轨。当前声音链读取已关联的旁白音频与项目背景音乐，尚不自动提取视频内嵌原声。电平表从该音轨读取每秒 100 个双声道峰值／RMS 窗口，显示静音前的节目电平及实际测量的整段响度；播放静音不改变处理结果。关闭可选处理并将增益归零后，不暗中降噪、压低或归一化，仍保留必要的区间拼接、音乐混合与格式转换。

“文稿剪辑与停顿清理”可选择词句或手选时间范围，先预览同步剪去画面、旁白和字幕的候选，再确认应用。只有真实语音识别的逐词时间戳、音频 ID 和源哈希均匹配时才提供逐词选择；手改、估时或句段结果按句段／手选编辑，不冒充逐词对齐。停顿候选来自实际源音频检测，识别文字的间隙不作为静音；修改检测参数会清除旧候选。删除按项目帧率向外对齐，保留至少 0.5 秒；恢复只还原当前分割／裁剪窗口中的原音视频与字幕，保留当前标题和样式。每次应用进入一步撤销，保存失败重试同一份草稿。背景音乐始终保持项目绝对时间。

非破坏剪辑以微秒保存共享、不可原地改写的原始来源与保留区间计划，原始字幕只保存一份，分割和裁剪引用计划窗口。旧项目未显式裁剪的长旁白按真实媒体全长播放，测量结果按素材版本缓存，不静默写回项目时长。声音处理与文稿剪辑已通过本地验收；当前全量 417 项自动测试、107 条浏览器流程及类型检查／构建通过，Windows 原生与真实云服务仍需对应环境验收，详见 [读取与编辑验收](docs/workspace-editing.md#验证与边界)。

“AI 微调”可为当前未锁定镜头重新生成文案、图片、配音或视频。选择相应能力的模型并填写本次调整要求后，结果保存在候选历史中；比较当前内容与候选，勾选文本字段或选择媒体候选后才应用。时长需要单独勾选。生成及候选随执行数据保存，关闭窗口后可重新打开；应用进入撤销／重做与草稿恢复。生成后修改过的相关字段会阻止旧候选覆盖，无关标题和其他镜头修改会保留。替换配音或视频从新素材开头开始，并保留另一种媒体的裁剪位置；替换配音后请重新核对字幕对齐。

“角色参考库”保存人物设定和最多四张公共参考图，可跨项目复用；在镜头属性中选择角色，绑定操作可撤销并跨重载恢复。运行固定当时的角色与图片快照，文字模型读取角色文字设定，支持图像参考的图片／视频适配会发送实际参考图；不支持的组合在提交前明确拒绝。角色设定或参考图更新后，旧的相关生成产物不能直接覆盖。角色与公共参考图随项目内容备份导入为独立副本；引用中的图片不能删除。

模型连接按协议与能力展示常用参数，保留高级 JSON 中的服务专用字段。结构化表单与 JSON 同步往返，已识别的其他能力参数不会混入当前请求；高级字段仍需由所接服务支持。可手动设置 USD／CNY 单价，仅用于费用估算，留空代表未知，清除价格会持久保存。

“费用记录”按制作任务归档，可筛选项目、加载更早任务，并打开任务详情。任务汇总覆盖该任务全部费用；详情按页显示步骤、镜头、模型、服务返回用量、当次价格和实付记录，原任务记录不可用时仍保留账目。查看详情后返回，会保留原任务列表与焦点。

费用按运行保存价格快照和服务实际返回的用量；没有完整用量或价格时显示待核对，不假定零费用。图片、视频和配音可按请求规格估算，配音优先按字符、识别优先按实际音频分钟，两种替代单位不相加。实际支付金额与币种依据账单手动登记，独立于估算，币种分别汇总；修改已加载的较早明细后同步更新该明细与任务汇总，修订冲突时保留输入。恢复已完成活动不会重复记账；外部提交未知时保留待核对状态。项目内容备份不包含工作区的执行与费用历史。

镜头属性的“资料引用”和项目设置的“资料与事实主张”使用同一资料表。可粘贴正文、导入 UTF-8 TXT／Markdown／有文字层的 PDF，或读取 HTTP(S) 网页；Wikipedia 关键词检索先提供线索，选中读取后才成为正文来源。每份资料保存实际正文、采集时间和 SHA-256，不会因原网页更新而静默替换。项目最多 20 份资料，每份正文最多 100,000 字符；文件最多 10 MB，PDF 最多 80 页，扫描件需先 OCR。

选择文字模型后可从已保存的资料片段整理证据候选。候选的摘录必须逐字对应本次实际送入模型的原文，伪造来源或无法定位的摘录会被排除；模型不能直接标记“已核验”。选定候选后加入项目，由用户核对来源、定位和备注，再绑定镜头。修改主张或证据会回到待核验；修改镜头引用遵守锁定状态。来源和引用一起进入撤销／重做、草稿恢复及项目备份，保存失败可重试而保留输入。

项目设置的“画面引用编号”可选择显示当前镜头的资料编号及待核验／争议／证据缺失状态。完整引用目录、摘录、定位和校验值写入导出的 `timeline.json`，不复制来源全文到成片目录；关闭编号仍保留目录。资料全文随项目内容备份保存。研究结果可在步骤产物中重新打开审阅，重复加入同一候选不会覆盖后来人工修改的资料。

镜头属性中的“科普画面模板”提供流程讲解、双侧对比和柱状数据图，支持标题、内容、配色与显现动画；默认数据明确标为示例。预览与实际编码共用模板，分割与裁剪保留原动画进度；暂时使用模板时保留原图片／视频关联，切回原画面即可恢复。模板编辑支持撤销、重做及草稿恢复。

项目设置的“项目字幕样式”和镜头配音区域的“镜头字幕样式”可调整无衬线／衬线字体、字号、字重、文字与背景颜色、背景透明度、上下位置及每页行数。镜头可以覆盖项目默认，也可恢复继承；预览与实际烧录共用排版，SRT 保留文字和时间。样式不修改字幕内容或识别时间戳，编辑可撤销并跨重载恢复。

“系列模板”保存可复用的风格文字、字幕样式和新镜头画面预设。新建项目可选择模板；现有项目可先预览再选择应用范围，也可把当前系列设置保存为模板。可选同步打开窗口时已有未锁定镜头的字幕覆盖、模板配色与动效，镜头正文、事实引用、媒体和图表数据保留。模板按修订复制进项目，库中后续编辑或归档不会改变已创建的项目。

导出面板的“多比例批量导出”可以从同一已保存修订生成横屏、竖屏、方形或自定义规格，逐项展示进度与文件路径。批次固定项目与实际素材快照，各目标独立保存；关闭窗口不会取消任务，失败或重启后可继续，已校验的成功项会跳过。批量导出仅执行本地渲染，不发起模型生成，也不修改项目的视频规格。

流程画布支持滚动平移、Ctrl + 滚轮缩放、空格 + 拖动平移，以及方向键移动所选步骤。背景任务刷新会保留本地编辑，切换视图或离开工作台前保存流程；发生外部流程版本冲突时，保留编辑并提供明确的重新载入操作。

交互实现参考 [Motion Canvas Player](https://github.com/motion-canvas/motion-canvas/blob/main/packages/core/src/app/Player.ts) 的播放与定位分离、[Excalidraw](https://github.com/excalidraw/excalidraw/blob/master/packages/common/src/utils.ts) 的最新指针位置合并，以及 [React Flow 性能指南](https://reactflow.dev/learn/advanced-use/performance) 的稳定组件与事件引用。播放状态仅由预览和时间尺订阅；图片按素材版本共享缓存，视频定位等待上次解码完成后应用最新位置。

工作区结构参考 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness/tree/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/client/ui-layout)：最近项目位于左侧导航，项目操作集中在一行，镜头与制作步骤使用大纲标签切换，时间轴横跨预览和属性区域。两侧面板可收起；宽窗口支持拖动调宽、方向键微调与双击复位，并保存布局偏好。“专注预览”临时展开画面空间，退出后恢复原面板。窄窗口自动收拢导航并将属性移至下方。

界面动效使用 GSAP 与 `@gsap/react`，用于标签指示条、页面内容、对话框和操作提示。动画限于位移、缩放和透明度；组件卸载会清理动画，系统开启“减少动态效果”时即时呈现状态。时间轴拖动和播放头直接响应输入，播放时钟独立于界面动画。

项目可备份为包含 `project.json` 和素材文件的目录，再通过“我的项目 → 导入项目”恢复为独立副本。含文稿剪辑或声音处理的项目使用备份格式 2，并包含恢复源窗口所需的原素材；仍兼容导入旧格式 1，旧版本应用会拒绝格式 2。数据库 Schema 6 保护剪辑来源引用的素材，未被当前画面使用的原素材也不能误删。素材库支持保留、选择和移除未使用的版本；移除记录会保留磁盘文件。混音、波形和电平等派生缓存不代替原素材备份。

工作区摘要与当前项目分开读取；进入制作记录并选择“查看步骤”后，才按需读取冻结步骤、实际输入、产物版本及活动日志；历史版本可以并排比较后应用，诊断可导出为本地压缩文件，日志每页最多 100 条。详见 [制作步骤详情](docs/workspace-editing.md#制作步骤详情)。素材库按页加载，后台刷新只获取变化的项目与素材版本。

镜头／项目属性、增删、复制、排序及步骤产物应用共用撤销与重做历史。使用工具栏或 Ctrl/⌘ Z、Ctrl/⌘ Shift Z（Ctrl Y 也可重做）。连续输入和一次缩放拖动合并为一步；已保存内容的撤销／重做创建新修订，未保存的操作先保留为草稿。草稿和最多 50 步增量历史按工作区与项目保存在本机 IndexedDB，重新打开项目时恢复；外部修改会保留人工草稿，并提供逐项比较和合并。草稿存储失败会明确提示，项目备份仍通过备份功能创建。流程画布继续使用切换前保存机制。

应用外壳采用接近不透明的轻磨砂材质，布局按钮保持独立间距和明确选中状态；明暗主题、减少透明效果偏好及不支持背景模糊的环境均有稳定底色。材质与细线阴影参考 [DeepSeek Harness 样式规范](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/web-styling.md)。读取接口、修订语义和本机基准见 [读取与编辑验收](docs/workspace-editing.md)。

## 模型和 Skill

在“模型连接”配置协议、服务地址、模型 ID 和能力。云模型使用系统凭据库；浏览器开发预览的密钥只在当前开发服务进程内存中保存。

支持 OpenAI 兼容文本、生图、配音接口，Ollama 文本、Seedream 生图、Seedance 视频、Qwen TTS、ComfyUI 和声明式自定义 HTTP。模型支持的具体尺寸、时长、音色和模型 ID 需要按照所接服务配置；真实云端验证需要用户自己的服务连接。

ComfyUI 高级参数使用 `workflow` 保存 API 格式的工作流，`inputMapping` 将 `prompt`、`narration`、`width`、`height`、`seed` 映射到“节点编号.输入名称”。自定义 HTTP 支持 `requestPath`、`requestTemplate`、`resultUrlPath`、`resultBase64Path`，异步接口另设 `taskIdPath`、`pollPath`、`statusPath`。模板变量包括 `{{prompt}}`、`{{narration}}`、`{{model}}`、`{{width}}`、`{{height}}`、`{{duration}}`。

Skill 可从本地目录、ZIP 或 GitHub 仓库导入，资源与版本随导入保存。Skill 中的 JavaScript 工具默认停用，需要单独启用；“工具连接”可登记 MCP 本地进程或 HTTP 服务，再绑定至 Agent 步骤。工具进程的工作目录和环境变量会受控，但其执行权限属于本机用户权限范围。

当前工作区按单实例、每项目一个活动任务运行，节点按依赖顺序执行。重用子流程、并行制作调度和完整多轨剪辑属于后续扩展。

## 执行与恢复

工作流使用 SQLite 检查点。模型与工具活动具有稳定操作标识，并保存输入摘要、结果和远端回执。继续执行会复用已经完成的活动；重新生成创建新的运行与操作标识。

人工审阅可以跨重启继续。外部提交结果不明确时会等待核对；已有远端任务编号时继续查询原任务。本地编码中断后可复用完整镜头并重新处理未完成片段。应用退出期间本地任务停止，下一次启动从持久记录继续。

完整约束见 [持久化执行](docs/durable-execution.md)。
